### Hi, I'm Atif, an AI/ML engineer

I build computer-vision and vision-LLM systems, from model training to production APIs. Based in Islamabad, open to AI/ML engineer roles.

**What I work on**
- Computer vision pipelines: object detection (YOLO) feeding vision-language models

- GPU performance: CUDA kernels, streams, Tensor Cores for faster training

**Selected work**
- [industrial-surveillance-analytics](https://github.com/atifibrahim7/industrial-surveillance-analytics): CCTV clips go through local YOLO detection, then a vision-LLM analyzes activity and safety. Searchable REST API, hourly/daily reports.
- [HumanAi-Music-Classification](https://github.com/atifibrahim7/HumanAi-Music-Classification): detects AI-generated vs human music. Compares 4 models (CNN, autoencoder, transformer, hybrid); best is 85.5% accuracy. Dockerized Flask API.
- [NeuralNetwork-Parallelization](https://github.com/atifibrahim7/NeuralNetwork-Parallelization): MNIST network trained on GPU, ~16x faster through CUDA optimizations.
- [Real-Time-Crime-Analytics](https://github.com/atifibrahim7/Real-Time-Crime-Analytics---Intelligent-Alert-System): Lambda architecture on Chicago open data using Kafka, Spark, Storm, PostgreSQL, MongoDB and Streamlit.
- [Cuda-Implementation-of-Edge-Detection](https://github.com/atifibrahim7/Cuda-Implementation-of-Edge-Detection): GPU-accelerated Canny edge detection.
